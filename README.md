# Secret Glow

Landing page da loja Secret Glow, feita em HTML, CSS e JavaScript sem etapa de build.

## Visualizar localmente

Abra `index.html` no navegador. As fotos dos produtos ficam em `images/` e são carregadas por caminhos relativos.

## Personalizar

- Atualize os textos e nomes dos produtos em `index.html`.
- Troque as fotos dentro de `images/` mantendo os nomes ou ajuste os caminhos no HTML.
- O WhatsApp e o Instagram já estão configurados nos links da página.
- As avaliações são exemplos fictícios e devem ser substituídas por depoimentos reais antes de divulgar a página.
